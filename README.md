# TempoRun 🏃‍♂️🎵

**Run to the beat.** An Android + Wear OS run tracker that plays music matched to your live running cadence — analyzed entirely on-device, with no server and zero recurring operational cost.

## How it works

1. Cadence detected from the accelerometer within ~10 s of run start
2. Engine targets track BPM = cadence (or cadence/2 with half-time feel)
3. Next track picked from the pre-analyzed library within ±4 BPM
4. Cadence drift > 4 BPM for 15 s → re-queue at the next track boundary
5. While locked: the combo meter builds → sync points × multiplier (rhythm-game rules)
6. Songs roll into rotation every N lifetime km — exercise-as-progression

## Architecture (zero backend)

- **Phone:** Kotlin, Jetpack Compose, Material 3, Media3 (ExoPlayer), Room, Health Connect, WorkManager
- **Wear OS:** standalone run tracking + cached tempo-tagged playlist, synced via the Wear Data Layer
- **Tempo analysis:** on-device beat detection (TarsosDSP-style), run overnight while charging on Wi-Fi
- **Recurring opex: $0/month.** One-time costs: $25 Play developer account. No servers exist to keep alive.

## Gamification

- **Combo meter** — seconds continuously locked × multiplier (×1 → ×4); breaks on lock loss
- **Per-song personal bests** — best lock streak per track, "NEW PB!" moments mid-run
- **Song roll-out** — tracks unlock into rotation from lifetime distance (all computed locally)
- **Smart playlists** — generated by tempo zone, genre, era/decade, energy, liked-only

## Roadmap

- **P0** Engine spike (2 wks) — cadence + beat detection validation on real hardware
- **P1** Phone MVP (4 wks) — run tracking, synced playback, history, sync score
- **P2** Wear OS (3 wks) — phone-free runs, watch battery budget
- **P3** Beta + polish (3 wks) — gamification layer, playlist builder, Health Connect, export, closed beta
